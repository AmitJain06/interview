All Nodes Distance K in Binary Tree

LeetCode 863 · Tree · DFS · BFS

Given the root of a binary tree, the value of a target node, and an integer k, return an array of the values of all nodes that have a distance k from the target node.

  1. Treat the tree as an undirected graph: store each node's parent while running an initial DFS.
  2. Start a BFS from the target node, marking visited nodes so we never walk back up.
  3. Collect the values of every node reached at exactly level k.
